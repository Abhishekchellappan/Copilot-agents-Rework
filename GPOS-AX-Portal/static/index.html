Platform Architecture Overview

GPOS AX Portal serves as a unified intelligent control plane that orchestrates multi-agent tasks via the Model Context Protocol (MCP). Each agent connects directly to dedicated microservices running inside your Kubernetes cluster:

🗂️ Jira MCP Server Communicates with jira.lge.com for sprint reports, burndown charts, and backlog audits.
🖥️ Device MCP Server Maintains persistent SSH connections to test boards for benchmarks, shell commands, and GDB crash analysis.
🤖 AI Supervisor Cross-references crash dumps from target devices with open Jira defect tickets for end-to-end RCA.

GPOS Jira & Governance Platform

Unified governance suite combining real-time Sprint Health & Compliance Dashboards with an AI-powered conversational Jira Agent.

Jira Sprint Dashboard Guide

Activity Stream (Mentions Today)

Why it's helpful: Aggregates live team updates, comments, and direct @mentions across all tickets today into one real-time feed. Eliminates manually clicking through dozens of Jira tickets to catch urgent blocker mentions or developer queries.

Missing Fields & Compliance Tracking

Why it's helpful: Audits the Developer Workload table to instantly identify non-compliance across the team: stories missing Story Points, empty descriptions, or missing assignees. Ensures backlog hygiene before sprint commitments and retrospectives.

At-Risk Items Radar

Monitors 3 critical risk categories with real-time indicators:

  • Overdue Tickets: Active items that have passed target completion dates.
  • Blocked Tickets: Items flagged with technical impediments or PR blockers.
  • Unassigned Tickets: Orphaned sprint tasks without an assigned owner.
Sprint Burndown & Status Doughnut

Visualizes active sprint completion velocity in real-time. Compares ideal story point burndown against actual remaining points, while the Status Doughnut provides an immediate ratio of To Do, In Progress, and Done.

GPOS Jira Agent Studio Capabilities

EXACODE LLM Configuration (Copy-Paste Ready)

Open Settings (gear icon in sidebar) and paste these values:

API Endpoint https://api.exacode.lge.com/v1/chat/completions
Model Name Chat-EXACODE-A
API Key Your personal EXACODE SWE (API) Key (not your AD or Jira password)

Known EXACODE Limitations

  • VPN / Intranet Required: EXACODE is strictly hosted on LG's corporate network. Working remotely requires LG VPN.
  • Context Window Caps: Very long chat sessions or large code dumps may get truncated. Start a New Chat periodically for optimal responses.
  • Peak-Hour Rate Limits: High demand during business hours may lead to temporary throttling. Simply retry after 5–10 seconds.
  • Alternative LLM Providers: If EXACODE is down, you may configure Azure OpenAI or GitHub Models in Settings if your cluster has internet access.
Why am I getting "Missing Jira PAT" error?

You haven't saved your Jira Personal Access Token yet. Open Settings (gear icon in sidebar), paste your Jira PAT from jira.lge.com, and click Save Settings.

Why does my login say "Account Pending Approval"?

All first-time AD sign-ins require one-time approval by a designated platform admin (abhishek15.c / varun.baba) from the Admin Control Center to ensure proper access governance.

Why does Device Agent report "All connection attempts failed"?

This happens if the Device MCP server is unreachable or if DEVICE_MCP_SERVER_URL is missing in your Kubernetes deployment environment. Verify that the Device Agent pod is healthy in namespace ai-user2.

How do I switch between different Jira projects?

Simply type or select your project key in the input box at the top navigation bar. The sprint dashboard and conversational agent will immediately shift focus to the new project.

EXACODE — Known Limitations

  • VPN / Intranet required — EXACODE is only reachable on the LG corporate network. It will not work from home without VPN.
  • Context window limits — Very long conversations or large code dumps may be truncated. Keep prompts focused.
  • Peak-hour rate limits — Heavy usage during business hours may cause slow responses or temporary throttling. Retry after a few seconds.
  • Alternative providers — If EXACODE is unavailable, you may configure Azure OpenAI or GitHub Models in LLM Settings, provided your cluster has internet access or a corporate proxy.
